Hero Banner Image

Separate banner per theme — visitors in light mode and dark mode can see completely different images. Needs a wide banner shape (around 2.36:1, like the default 2560×1086), at least 1600px wide, under ~2MB.

Admin

Banner Position

The image's horizontal focal point — set separately for desktop and mobile since a wide banner crops very differently on a phone screen. Applies to both light and dark banners.

Hero Ticker

The scrolling line of text pinned to the very top of every page. Add, edit, or reorder — the order here is the order it scrolls.

Manage Services

Fonts

Only fonts that exist as files in this site's /fonts folder can show up here — nothing is uploaded through this panel. Push new .woff2 files to GitHub, run node scripts/generate-font-manifest.mjs, redeploy, and they'll appear in the lists below.

Bengali Font

Used automatically when a visitor switches the site language to Bangla. "Noto Sans Bengali" always works (loaded from Google Fonts) — anything else needs its files added to /fonts the same way.
